Éditeur de couleurs d'image

Présentation

Cet outil vous permet de modifier une image directement dans votre navigateur : remplacer une couleur par une autre, supprimer une couleur pour obtenir un fond transparent, recadrer et exporter dans plusieurs formats.

Accès libre et gratuit. Aucune création de compte n'est nécessaire. Toutes vos images sont traitées en local sur votre appareil : rien n'est envoyé vers un serveur.

Utilisez les sections ci-dessous (cliquez sur le titre pour les ouvrir ou les replier). Quand une section est repliée, un court rappel indique son rôle.
